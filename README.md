# Задача коммивояжёра

Практическая работа №5.2 по дисциплине «Алгоритмы и структуры данных».

**Студент:** Грибенщиков Алексей Сергеевич, группа ЗКИ24-17Б

## Задача

Построить кратчайший маршрут, который начинается в Красноярске (`id = 3753`)
и проходит через все 6137 населённых пунктов Сибирского федерального округа
ровно по одному разу. Расстояние между пунктами считается как евклидово
расстояние между точками.

## Алгоритм

1. **Жадный алгоритм (ближайший сосед).** Из текущего пункта едем в ближайший
   непосещённый. Даёт начальный маршрут.
2. **2-opt.** Ищем две дороги маршрута, которые выгодно заменить, и
   переворачиваем кусок маршрута между ними. Так распутываются петли.
3. **Or-opt.** Вырезаем кусок из 1, 2 или 3 пунктов и вставляем его в другое
   место маршрута, если так путь становится короче.
4. Or-opt и 2-opt выполняются по очереди, пока длина маршрута уменьшается.

Для ускорения у каждого пункта заранее находятся 10 ближайших соседей,
и улучшения ищутся только среди них.

Все функции алгоритма в `tsp.py` универсальные: принимают список точек и
номер стартовой точки и не зависят от конкретных данных.

## Результат

| Этап | Скор |
|---|---|
| Жадный алгоритм | 1050.43 |
| После 2-opt | 931.29 |
| После Or-opt + 2-opt | **880.15** |

Скор равен сумме всех расстояний маршрута, делённой на 100.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Программа читает `data.csv` и записывает результат в `solution.csv`
(6136 строк в формате `номер;расстояние`).

## Файлы

- `tsp.py` функции алгоритма
- `main.py` запуск: чтение данных, построение маршрута, сохранение результата
- `data.csv` исходные данные
- `solution.csv` результат
- `pylintrc` настройки проверки кода
